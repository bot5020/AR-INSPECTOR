# Установка и запуск

Подробный воспроизводимый сценарий с локальной vision-моделью и демонстрационными фото — в [REPRODUCE.md](REPRODUCE.md).

## Требования

- Python 3.10 или новее.
- Интернет на этапе установки пакетов и весов YOLO-World.
- LM Studio или другой локальный сервер, который предоставляет vision-модель через OpenAI-совместимый API.

## Установка

Из корня проекта:

```bash
# macOS / Linux
./launch.sh setup
```

```powershell
# Windows
.\launch.bat setup
```

Команда создаёт виртуальное окружение, устанавливает зависимости и подготавливает веса детектора. Затем настройте VLM согласно разделу 3 в [REPRODUCE.md](REPRODUCE.md).

## Запуск

Когда локальная модель запущена:

```bash
# macOS / Linux
./launch.sh run --no-lms
```

```powershell
# Windows
.\launch.bat run --no-lms
```

На сервере откройте `http://localhost:8081/`. Для камеры телефона подключите его к той же Wi-Fi-сети и откройте HTTPS-адрес `https://<IP сервера>:8080/`, напечатанный в консоли. Разрешите браузеру доступ к камере.

Если телефон не открывает страницу, разрешите входящие подключения на TCP-порт `8080` в брандмауэре сервера. На macOS разрешите сетевые подключения для Python; на Windows используйте частный профиль сети.

Сервер должен оставаться запущенным во время осмотра. Остановить его можно сочетанием `Ctrl+C`.
