## Что получилось на проверенном стенде

Qwen 3.5 4B MLX, контекст 6144, один слот, thinking выключен, версия промпта `inspect-36d13c54a7`:

- Фото 01: коррозия корпуса отмечена в 3/3 прогонах, 15,9–16,9 с.
- Фото 02: один прогон, 13,4 с; оценки отдельных узлов отличаются от первого ракурса. Это пример продолжения осмотра, а не доказательство улучшения точности.
- Фото 03: нагар контактов отмечен в 3/3 прогонах, 12,9–14,6 с. Соседний блок модель спорно подписывает как реле контроля фаз; эти метки также нужно проверять.
- Фото 04: бак и вводы найдены в 3/3 прогонах, 12,6–14,9 с. Выводы о ПБВ, его внутренних контактах и уровне масла на этом удалённом снимке не подтверждены изображением. Фото оставлено для проверки ограничений.

Одинаковые подготовленные фото не являются независимым тестом промышленной точности. На другой модели и оборудовании ответы и время могут отличаться.

Для результата по фотографии смотрите «На этом снимке»/«Осмотр ИИ». Общий статус узла дополнительно учитывает ресурс, ТО, измерения и историю. Зелёный результат означает отсутствие найденных внешних признаков, а не исправность оборудования.

## Автоматический повтор

Из корня проекта, при работающей модели `vlm`:

```bash
python scripts/evaluate_vision.py --cases demo/expert-photos/cases.json --runs 3 --label expert-demo
```

Используйте Python из `.venv`: `.venv/bin/python` на macOS/Linux, `.venv\Scripts\python.exe` на Windows.
Скрипт использует отдельную временную базу и сохраняет отчёт в `data/eval/`. Он проверяет выбранные ожидаемые узлы и предупреждения; лишние метки и координаты рамок требуют отдельной ручной проверки. Не считать `passed` общей точностью модели.

[SHA-256 и сопоставление с карточками](manifest.json). [Пошаговая речь для демонстрации](ПОРЯДОК_ПОКАЗА.txt).
