# QR и учебные шильдики

QR для оборудования, не для подключения телефона. В приложении включите камеру и наведите на один QR; либо загрузите его изображение и нажмите «ID».

| Карточка | QR | Заводской номер для шильдика | Инвентарный номер |
|---|---|---|---|
| PUMP-001 | [QR](QR-PUMP-001.png) · `KST:EQ:PUMP-001` | `2019-0471` | `ИНВ-004712` |
| CAB-003 | [QR](QR-CAB-003.png) · `KST:EQ:CAB-003` | `ШУ-2020-118` | `ИНВ-005130` |
| TR-001 | [QR](QR-TR-001.png) · `KST:EQ:TR-001` | `ТМГ-1708-3321` | `ИНВ-002208` |

Для шильдика откройте `nameplate-<ID>.png`, наведите камеру на текст и нажмите «ID». На этих изображениях нет QR: проверяется чтение номера моделью. Это учебные таблички из данных карточек, не фотографии заводских паспортов.

Совпавший прочитанный номер выбирает карточку. Без читаемого номера модель предлагает наиболее похожую карточку с объяснением и оценкой уверенности; пользователь подтверждает выбор. Пустой кадр и совершенно неподходящий объект могут не дать кандидата.

Все QR для текущего локального каталога также доступны на http://localhost:8081/labels .
