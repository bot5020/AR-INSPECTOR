# AR-Инспектор

Прототип для осмотра промышленного оборудования с телефона или планшета. Локальный сервер связывает карточку оборудования и историю обслуживания с камерой, QR-кодом/шильдиком, подсветкой узлов, предварительными наблюдениями vision-модели и решением инженера.

## Быстрый запуск

Нужен Python 3.10+ и локально запущенная vision-модель с OpenAI-совместимым API. Подробная настройка моделей, сети и камеры: [INSTALL.md](INSTALL.md) и [REPRODUCE.md](REPRODUCE.md).

```bash
# macOS / Linux
./launch.sh setup
./launch.sh run --no-lms
```

```powershell
# Windows
.\launch.bat setup
.\launch.bat run --no-lms
```

Откройте `http://localhost:8081/` на сервере или HTTPS-адрес из вывода запуска на телефоне в той же Wi-Fi-сети. Учётные записи для демо создаются локально; пароли показываются на странице `/setup` и не входят в репозиторий.
